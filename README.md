# Pokerly

A poker night settle-up calculator. After each hand, pick the winner and tap what everyone else lost (in cents). At the end, Pokerly shows who pays whom, in dollars, either pairwise or simplified into the fewest payments.

- Open `index.html` in any browser, or use the hosted site on GitHub Pages.
- Games are saved in your browser. Use **History → Copy backup** to keep a copy.

## Making changes

Edit `index.html`, then:

```
git add .
git commit -m "Describe your change"
git push
```

GitHub Pages updates the live site about a minute after each push.
